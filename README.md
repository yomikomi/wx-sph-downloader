



# wx-sph-downloader
【微信视频号提取文案下载工具】下载视频，提取音频，提取文案，点赞数，转发数，收藏数，评论数导出数据到excel表格

## ✨ 功能特性
- ✅ 视频号视频下载
- ✅ 视频音频单独提取
- ✅ 视频提取文案
- ✅ 自定义下载视频时间范围和数量
- ✅ 抓取作品互动数据：点赞 / 转发 / 收藏 / 评论数量
- ✅ 批量导出采集数据至 Excel
- ✅ 可视化操作界面
