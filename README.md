# wx-sph-downloader
【微信视频号下载工具】下载视频，提取音频，点赞数，转发数，收藏数，导出数据到excel表格

## ✨ 功能特性
- ✅ 视频号视频下载
- ✅ 视频音频单独提取
- ✅ 抓取作品元数据：点赞 / 转发 / 收藏数量
- ✅ 批量导出采集数据至 Excel
- ✅ 可视化操作界面
